# HomeTimeJobs — Astro site

Driver-facing CDL job platform. A Paul Ann Media product (Trimmie Holdings).

---

## Run it locally

You'll need Node 18+ installed. From this folder:

```bash
npm install
npm run dev
```

Open http://localhost:4321

To build for production:

```bash
npm run build
```

Output lands in `dist/`.

---

## Deploy tonight — Netlify (easiest, forms included)

1. Push this folder to a new GitHub repo
2. Go to netlify.com → **Add new site** → **Import an existing project**
3. Connect the repo. Netlify auto-detects Astro:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Deploy

**Point the domain:** Netlify → Domain settings → Add custom domain → `hometimejobs.com`.
Netlify gives you DNS records; add them in GoDaddy under DNS management. SSL is automatic.

### Why Netlify first
The lead form uses **Netlify Forms** — it works with zero backend, zero config.
Submissions appear in your Netlify dashboard and can email you on each one.

If you'd rather use Vercel or Cloudflare Pages, swap the form to
[Formspree](https://formspree.io) — change the `action` in
`src/components/LeadForm.astro` to your Formspree endpoint and remove the
`data-netlify` attributes.

## What's already built for AI visibility

- **Organization schema** sitewide, with `parentOrganization` → Paul Ann Media
- **FAQPage schema** on `/home-time` and `/pay` — the highest-value citation format
- **llms.txt** summarizing the site and its positions for language models
- **robots.txt** explicitly allowing GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot, Applebot-Extended
- **Sitemap** auto-generated by `@astrojs/sitemap`
- **Static HTML** — fully readable by crawlers that don't execute JavaScript
- Canonical URLs, OG tags, semantic headings throughout
